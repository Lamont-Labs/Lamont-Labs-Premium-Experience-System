# Resource integration policy

This repository is an **app-development resource library**, not a platform.

Do not bulk-copy third-party repositories. Start with curated links and usage notes. For code imports, check exact file licenses and notices, upstream revision, commercial redistribution permission, security and dependency compatibility. Record decisions before importing.

The `catalog/resources.json` entries are **candidates**; their licenses and maintenance status have not been independently certified by this catalog. `dependency` describes the intended future use, not an installed dependency. Alternatives (e.g. Roborazzi and Paparazzi) must be evaluated before choosing one.

Never force a central LL-PES runtime into a target app. No target app should depend on the availability of this repository to launch or render.

## Adoption evidence
Record target app, branch/commit, selected resource and pinned version, affected user journeys, test commands/results, screenshots where applicable, and rollback steps.
