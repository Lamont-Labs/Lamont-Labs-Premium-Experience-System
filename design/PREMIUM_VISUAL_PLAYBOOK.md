# Premium visual playbook

## Hierarchy
Every screen should have one clear primary action. Prioritize information needed to complete the current job. Use contextual drill-down rather than stacking repetitive dashboard cards.

## Typography
Use a limited scale with clear heading, metric, label and supporting-text roles. Support system font scaling and real content lengths. Never use low-contrast thin text merely to appear premium.

## Surfaces and glass
Glass is optional. Use blur, tint, specular highlights and edge contrast only where hierarchy benefits. Keep interactive foreground content crisp and legible; offer a solid-surface fallback for reduced transparency and performance constraints.

## Navigation
Prefer short, predictable paths. Keep persistent navigation compact; maintain correct back behavior, deep links and unsaved-state handling. Do not transplant a navigation scheme from another product without validating its tasks.

## Motion
Use movement to communicate cause and effect. Respect reduced-motion preferences. Avoid animations that delay a user trying to record, save or approve something.

## States
Show loading, empty, offline, error, disabled, pressed, focused, saving, saved and interrupted states where applicable. State preservation is a feature, not visual decoration.

## Review
Compare before/after screenshots from the same device size and state. Document defects, subjective assessments and test measurements separately.
