# New app — premium-first workflow

1. Define target users, three primary jobs, platform and offline requirements.
2. Create an Experience DNA profile using `templates/experience-dna.example.json`; replace example values with approved product-specific identity.
3. Design the primary task journey and navigation before building decorative screens.
4. Choose native platform components first. Keep optional libraries version-pinned.
5. Define semantic tokens, typography, spacing, interaction states and accessible targets.
6. Implement first-use, returning-user, empty/error/loading, interruption and persistence flows.
7. Build a component state gallery and screenshot baselines.
8. Execute the verification checklist in `workflows/VERIFICATION.md`.
9. Record evidence per source revision; no build-only acceptance.
